IMPORTANT: This is NOT a certified clean vector master. The wordmark source was traced from imagery and retains potential geometric artifacts when magnified. The generated PNGs are softened and downsampled for practical web display; at header size they should be assessed in-browser.

Use: djhq-wordmark-dark-transparent.png on dark backgrounds; djhq-wordmark-light-transparent.png on light backgrounds. HQ icons are provisional for browser app testing; check 16x16 readability.

No SVG wordmark is included on purpose: earlier vector versions distorted the DJ and HQ joins. Reconstruct professionally with a vector editor if large-format or print usage is required.
